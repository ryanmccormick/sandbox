# light-menu

Light Menu as a library. Peer deps: `react`, `react-dom`, `tailwindcss` v4.

```tsx
import {
  LightMenu,
  LightMenuButton,
  LightMenuDivider,
  LightMenuItem,
  LightMenuSubMenu,
} from 'light-menu'
import 'light-menu/styles.css'
```

The demo app in `src/` consumes that same public entry.
